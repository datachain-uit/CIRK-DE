# CIRK-DE

Code, data, pre-registration and results of the study "Random-Key
Differential Evolution with Controlled Gene Insertion for Fixed-Size Gene
Selection: A Pre-registered Evaluation" (submitted to TAIMMA 2027).

CIRK-DE (controlled-insertion random-key differential evolution) is a
wrapper that selects panels of exactly k genes. Branch `taimma-2027` holds
the study. Tag `taimma-2027-submission` marks the submitted state. The code,
the processed data, the splits, the result packages of every session and the
aggregated results are in this repository.

## Repository layout

| Path | Content |
|---|---|
| `mpqda/` | Method code: encoding, fitness, archive, DE variants, baselines, phase B, registration gate |
| `scripts/` | Runners, operator simulation, table and figure scripts |
| `tests/` | Unit tests and smoke tests on synthetic data |
| `docs/taimma/` | Pre-registration, amendments, reproduction guide, simulation data |
| `data/` | Processed expression matrices, sample metadata and splits of the seven datasets |
| `result_packages/` | Result packages of the eleven Kaggle sessions, unchanged |
| `notebooks/sessions/` | Executed Kaggle notebooks of these sessions |
| `notebooks/kaggle_taimma_runner.ipynb` | Runner generated by `scripts/make_kaggle_notebook.py` |
| `tables_v2/` | Aggregated results behind the numbers of the paper |
| `vendor/` | Unmodified copy of the code used for data loading, splits and baselines, with its MIT licence (`vendor/VENDORED.md`) |

## Data

The expression data come from public GEO series and from the TCGA LUAD and
LUSC cohorts. `data/` holds them in the layout read by the code
(`KLTN_DATA_ROOT`).

| Folder | Dataset | Use |
|---|---|---|
| `data/experiment-data-geo-target/gse10245/` | GSE10245 | Confirmatory cohort |
| `data/experiment-data-geo-target/gse30219/` | GSE30219 | Confirmatory cohort |
| `data/experiment-data-geo-target/gse37745/` | GSE37745 | Confirmatory cohort |
| `data/experiment-data-geo-target/gse42127/` | GSE42127 | Development data |
| `data/experiment-data-perm/tcga_luad_lusc_primary_tumor/` | TCGA LUAD and LUSC, primary tumours | Gene space; source of the three development subsets |
| `data/experiment-data-b7/gse31210_egfr/` | GSE31210, EGFR mutation | External task (B7) |
| `data/experiment-data-b7/tcga_luad_egfr/` | TCGA LUAD, EGFR mutation | External task (B7) |

Each folder holds `expression.h5` and `metadata.csv`. The folders of the six
datasets that are split into folds also hold `repeated_splits.csv`. The runner stops when the
SHA-256 of a `repeated_splits.csv` differs from
`mpqda.config.EXPECTED_SPLIT_SHA256`. `data/SHA256SUMS.txt` lists every file
of `data/`. The development subsets `tcga_dev_a`, `tcga_dev_b` and
`tcga_dev_c` are rebuilt from the TCGA cohort by
`scripts/build_dev_datasets.py` (card: `docs/taimma/dev_datasets_card.json`).

    cd data && sha256sum -c SHA256SUMS.txt && cd ..
    export KLTN_DATA_ROOT="$(pwd)/data"

Files of 50 MB or more are not stored in Git. They are attached to the
release `taimma-2027-submission` as `cirk-de-data-large.zip`
(SHA-256 `527d2c14152bf8fb2ddaa2f33f71e6768ff53f6d6adc6b23e7ed343c35446fc3`). Unzip it at the root of the repository
before the check above (`unzip cirk-de-data-large.zip`). It holds:

- `data/experiment-data-perm/tcga_luad_lusc_primary_tumor/expression.h5`

## Pre-registration

The hypotheses, tests and reading rules were fixed in
`docs/taimma/PREREG-v2.md` before any run of CIRK-DE on the confirmatory data.

| Tag | Commit | Date | Content |
|---|---|---|---|
| `taimma-2027-prereg-v2` | `d5e72e4` | 2026-11-17 | Registration |
| `taimma-2027-prereg-v2.1` | `95333d0` | 2026-11-17 | Amendment A1 (`docs/taimma/T0v2_waiver.json`) |
| `taimma-2027-prereg-v2.2` | `f6b8bd2` | 2026-11-20 | Amendment A2 (HV6, `docs/taimma/PREREG-v2_A2.md`) |

Amendments are logged in Section 12 of `PREREG-v2.md`. The runner refuses to
run CIRK-DE on the confirmatory data unless HEAD carries one of these tags
(`mpqda/registration.py`). The registration documents name the repository
by its former name. Its history, including these commits and tags, was
transferred here unchanged.

The runs of QRK-DE and of the baselines followed `docs/taimma/PREREG.md`.
Its protocol was fixed in commit `35331ed` before the main runs, but the runs
started before supervisor approval, so it is not a pre-registration (see its header).

`notebooks/sessions/` the executed notebooks. Each package contains the
results under `results/survey_v2/taimma/`, the test logs, the command logs
and the `pip freeze` of its session. `result_packages/SHA256SUMS.txt` and
`notebooks/sessions/SHA256SUMS.txt` list their SHA-256.
`scripts/taimma_jobs.py show <job>` prints the commands of each job.

| Package | Session content |
|---|---|

| `S2_results.zip` | AUROC fitness (T1b), references T4, cost T6 |
| `S3_results.zip` | Ablation of QRK-DE (T2) and seed stability (T3) |

| `C1_results.zip` | CIRK-DE and DE-G on the three GPL570 cohorts (k in {2, 5, 10, 50}) and the two B7 datasets (k in {5, 10}) |
| `C2_results.zip` | Ablation of CIRK-DE (k in {2, 5, 10}) |

## Reproducing

`docs/taimma/REPRODUCE.md` gives the environment (Kaggle CPU image with
skrebate 0.8.4 and abess 0.4.11), the sessions and the commands that rebuild
every table. Set `KLTN_DATA_ROOT` to `data/` as above. To rebuild the tables
from the packages, unzip them into `$KLTN_DATA_ROOT` (for example
`unzip -n result_packages/C1_results.zip -d "$KLTN_DATA_ROOT"`) and run the
commands of Sections 3c and 4 of `REPRODUCE.md`.

The exact package list of session S0 is `docs/taimma/pip_freeze_S0.txt`,
copied unchanged from `logs/S0/pip_freeze_session.txt` of `S0_results.zip`
(MD5 `6af55eea01de6bb6b9b41ece2d33e480`, as in Section 11 of `PREREG.md`).

    python -m pytest tests -q
