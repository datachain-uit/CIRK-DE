# CIRK-DE

Code, pre-registration and results for the paper "Random-Key Differential
Evolution with Controlled Gene Insertion for Fixed-Size Gene Selection:
A Pre-registered Evaluation" (submitted to TAIMMA 2027).

CIRK-DE (controlled-insertion random-key differential evolution) is a
wrapper that selects panels of exactly k genes. Branch `taimma-2027` holds
the code of the study. Tag `taimma-2027-submission` marks the submitted state.

## Repository layout

| Path | Content |
|---|---|
| `mpqda/` | Method code: encoding, fitness, archive, DE variants, baselines, phase B, registration gate |
| `scripts/` | Runners, operator simulation, table and figure scripts |
| `tests/` | Unit tests and smoke tests on synthetic data |
| `docs/taimma/` | Pre-registration, amendments, reproduction guide, simulation data |
| `tables_v2/` | Aggregated results behind the numbers of the paper |
| `vendor/` | Unmodified copy of the survey code used for data, splits and baselines |
| `notebooks/` | Kaggle runner generated by `scripts/make_kaggle_notebook.py` |

## Pre-registration

The hypotheses, tests and reading rules were fixed in
`docs/taimma/PREREG-v2.md` before any run of CIRK-DE on the confirmatory data.

| Tag | Commit | Date | Content |
|---|---|---|---|
| `taimma-2027-prereg-v2` | `d5e72e4` | 2026-11-17 | Registration |
| `taimma-2027-prereg-v2.1` | `95333d0` | 2026-11-17 | Amendment A1 (`docs/taimma/T0v2_waiver.json`) |
| `taimma-2027-prereg-v2.2` | `f6b8bd2` | 2026-11-20 | Amendment A2 (HV6, `docs/taimma/PREREG-v2_A2.md`) |

Amendments are logged in Section 12 of `PREREG-v2.md`. The runner refuses to
run CIRK-DE on the confirmatory data unless HEAD carries one of these tags
(`mpqda/registration.py`). The registration documents name the repository
by its former name. Its history, including these commits and tags, was
transferred here unchanged.

The first stage of the study (initial wrapper) followed
`docs/taimma/PREREG.md`. Its protocol was fixed in commit `35331ed`
before the main runs, but the runs started
before supervisor approval, so it is not a pre-registration (see its header).

## Reproducing

`docs/taimma/REPRODUCE.md` gives the environment (Kaggle CPU image with
skrebate 0.8.4 and abess 0.4.11), the data layout (`KLTN_DATA_ROOT`), the
sessions and the commands that rebuild every table. Data and splits follow
https://github.com/datachain-uit/RNA-Seq-FS-Survey (tag `survey-v3-dmkd.2`).
The expression data are public GEO and TCGA datasets and are not stored here.
The runner checks the SHA-256 of the splits against
`mpqda.config.EXPECTED_SPLIT_SHA256`.

The exact package list of session S0 is `docs/taimma/pip_freeze_S0.txt`,
copied unchanged from `logs/S0/pip_freeze_session.txt` of `S0_results.zip`
(MD5 `6af55eea01de6bb6b9b41ece2d33e480`, as in Section 11 of `PREREG.md`).

    python -m pytest tests -q
